# ExamGenAI

ExamGen AI Pro is an AI-powered practice exam generator and real-time grading assistant. 
It enables students to upload reference PDF documents, automatically extract key topics, generate customized mock exams (MCQs, short answer, long answer, and scenario questions) using Gemini AI, and grade descriptive answers in real time with detailed suggestions.

## Features
- **PDF Document Processing**: Auto-extraction of textual references from PDFs.
- **Dynamic AI Test Generator**: Generate customized mock exams based on subject matter and difficulty.
- **AI-Powered pipeline grading**: Detailed descriptive feedback and marking analytics.
- **Real-Time Notifications**: Instantly notify users about document processing updates and exam grading results.

## Project Structure
- `/BACKEND`: Node/Express backend API.
- `/FRONTEND`: Vite/React frontend dashboard.
